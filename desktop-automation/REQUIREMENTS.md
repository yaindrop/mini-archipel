# 桌面自动化插件验收范围

用户在 2026-10-30 授权自主完成 P0、P1。插件 ID 为 `desktop-automation`。

| 优先级 | 需求 | 验收条件 |
| --- | --- | --- |
| P0 | 安装、升级、回滚 | 节点一条安装命令；已有 Runner App 不重签；辅助程序编译后再替换；失败恢复上一版；活动任务阻止升级 |
| P0 | 自检与授权引导 | 显示应用安装、权限、桌面会话、锁屏；打开对应系统设置并申请权限；系统认证留给用户，后台复验 |
| P0 | 统一接口与能力查询 | 使用现有 Agent/Console 插件鉴权和节点路由；提供 CLI、JSON 参数、能力清单与复用文档 |
| P1 | 后台任务 | 提交立即返回；请求先落盘；断连后查询/等待；重复 ID 不重新执行；内容冲突拒绝；取消不误杀无关 PID |
| P1 | 桌面协调 | 显示占用；暂停新任务；排队但未执行的任务在暂停后不能操作；人工接管前等待当前任务结束；支持恢复 |
| P1 | 诊断与界面 | 独立插件页面及节点入口；中英、桌面/手机；任务状态、结果和耗时；下载不含消息正文、输出或密码的诊断包 |

第一版接入 Codex 和 ZCode 已实测的适配器，并保留通用 AppleScript/程序执行入口。
节点控制与任意脚本执行分别显式启用。插件启停不结束已接收的任务，不退出被操作 App。
不修改 TCC 数据库，不收集密码；首次辅助功能授权仍可能需要用户点击开关。
取消聊天任务停止本地等待，不撤销已发送的消息或承诺停止模型。恢复聊天使用原请求 ID。
不新增另一套节点认证、调度服务、管理网站或 MCP 服务；使用现有工作台和插件 API。
