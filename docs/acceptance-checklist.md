# 新机验收清单

先注明节点类型、目标提交、验收日期。标记为“通过 / 不适用 / 待验证”，
不要把豁免算作失败，也不能把“配置已写入”当作“端到端已验证”。

## 共同要求

- [ ] 主机名、短用户名、SSH 别名、runner 名称全局唯一。
- [ ] 共享设置中，远程管理、远程登录、远程应用程序脚本三项同时开启，均允许指定运维账户访问。
- [ ] 远程登录：公钥 SSH 实际登录成功。
- [ ] 远程管理：运维账户具备观察/控制权限，实际连接后桌面可见且可操作。
- [ ] 远程应用程序脚本：从控制机发送只读远程 AppleScript，认证成功且返回结果。
- [ ] 防睡眠与显示器休眠设置生效（`pmset -g custom` 核对）。
- [ ] GUI 代理与独立 CI 代理双端口分离；经 CI 代理访问 GitHub 成功。
- [ ] 固定工具 PATH 正确；目标提交的工具链核对脚本返回 0。
- [ ] `pnpm install --frozen-lockfile` 成功；项目所需 SDK 冻结依赖可安装。
- [ ] 原生 Rust、WASM、Playwright Chromium 等项目依赖可运行。
- [ ] runner 只注册一次，名称与标签正确，GitHub 显示 online，实际接到一次验收作业。
- [ ] mini-archipel Agent 版本与其余节点一致；Runner 插件及独立控制权限按 CI 节点规则启用。
- [ ] 控制台与各节点插件可分别启停并持久保存；关闭插件时基础采集和现有 Runner / Worker 不受影响，恢复后重新上报。
- [ ] 作业完成钩子执行成功，日志无 warning，源码未被清理脚本改动。
- [ ] 壁纸、屏保、Spotlight、小组件、Siri 符合本机用途。
- [ ] 空闲时无遗留 Worker、浏览器、开发服务器或无关 GUI 程序。
- [ ] 记录本机的 APFS 用量、空闲 CPU、footprint、压缩与 swap 基线。

## 实体 Mac mini

- [ ] FileVault、SIP、防火墙开启；不设自动登录或免密 sudo。
- [ ] 接电启动、网络唤醒配置生效。
- [ ] 安排维护窗口，实际重启验证磁盘解锁、网络、桌面会话与远程恢复；未执行则注明。
- [ ] 风扇控制安装时完成四档实写验证；守护进程运行，负载行为符合预期。无配置变化时可引用既有验收记录，不重复压力测试。
- [ ] 需要容器能力时，Colima 可启动并运行 ARM64 容器；验收后停止，再授予容器能力标签。

## Tart macOS 客体

- [ ] 宿主机 FileVault 开启，镜像/备份受保护，运维连接在预期网络范围内。
- [ ] 客体 FileVault 标记“豁免”；自动登录、免密 sudo 允许保留。
- [ ] 风扇、接电启动、物理网络唤醒标记“不适用”。
- [ ] Colima VZ / 本机容器引擎标记“当前平台不支持”，不授予容器能力标签。
- [ ] 分别记录宿主机启动 Tart、客体登录及用户服务恢复的验证情况；未经重启不声称恢复测试通过。
