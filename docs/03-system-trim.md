# 3. 系统功能与桌面精简

原则：这台机器是服务节点，不是日用桌面。关掉一切与 CI 无关的发射/接收面。

## 已执行的裁剪

| 类别      | 操作                                            |
| --------- | ----------------------------------------------- |
| 蓝牙/近邻 | 关蓝牙；隔空投送"没有人"                        |
| 连续互通  | 关接力、iPhone 小组件/通知镜像/实时活动         |
| 接收      | 关隔空播放接收器                                |
| 共享      | 关文件共享等；保留远程登录与屏幕共享            |
| 壁纸/屏保 | 纯黑静态壁纸；屏保永不（`idleTime=0`）          |
| 小组件    | 隐藏桌面/台前调度小组件（进阶处理见下）         |
| Siri      | 关闭 Siri、语音唤醒、菜单显示；屏幕使用时间阻止 |
| 日用软件  | 空闲时退出一切不需要的 GUI 应用                 |

壁纸在系统设置里改；这类 GUI 设置项没有对应的可靠命令行入口。

## Spotlight：彻底关闭（可选，按需）

系统设置 → 聚焦：关全部结果来源与搜索改进；"搜索隐私"加入整个
Macintosh HD 与 `/System/Volumes/Preboot`。验证：

```sh
mdutil -a -s   # / 与 Data、Preboot 均应显示 Indexing and searching disabled.
```

`rg`、`find` 不受影响。恢复：在 GUI 移除整盘排除后执行 `mdutil -i on`。

## 小组件进阶（可选）

仅隐藏显示后，小组件进程仍会重启。进阶做法：核对通知中心与 chronod 确认
无真实实例后，用 `pluginkit -e ignore -i <精确扩展ID>` 停用不用的
WidgetKit 展示/意图扩展（实测两台各约 24+2 个），先保存原始 election 再
操作。实测分组内存约 166 MiB → 20 MiB。系统升级后需复核；二进制不删除。

## 明确不做的

- 不卸载受保护系统 App（国际象棋、家庭、照片、音乐等），不动 SIP 与系统
  卷签名。
- 不删 System/Preboot/Recovery。
- Siri 偏好已关；相关进程（assistantd 等）驻留约 150 MiB/台，SIP 拒绝进一步
  停用。
