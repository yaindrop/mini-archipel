# 10. SSD 清理与静默基线

## 已实际执行且可复现的清理

| 类别     | 操作                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 预装软件 | 删除 iMovie、GarageBand、Pages/Numbers/Keynote 创作套件等可选 App（约 6 GiB）及 Apple Loops/音色残留 |
| 用户缓存 | SiriTTS 模型、航拍壁纸、旧下载、临时安装目录等可重建数据                                             |
| 更新残留 | 确认无待装更新后删 `macOS Install Data/UpdateBundle`（约 1.6 GiB），保留受保护外层                   |
| 开发缓存 | pnpm/uv 官方 prune、`brew cleanup`；Rust/uv 缓存按需授权清空（会随 CI 重建）                         |
| 日志     | 旧 runner 日志清理，转由作业完成钩子持续维护                                                         |

## 明确不做的

- 不卸载受保护系统 App、不动 SIP/系统卷签名；不删 System/Preboot/Recovery。
- 受保护字体/词典（约 2 GB）没有可靠删除入口；翻译资源删后自动重现。
- ANE 编译任务是开机一次性负担，自行结束；不做循环清理。
- 不部署全量 debloat 脚本、不主动 purge 内存或循环杀进程。
- 旧机的一次性历史数据清理属于旧机专属操作；历史脚本不重放。

## 静默基线（示例：两台 M6/16G/245G，空闲无任务时）

| 指标           | 值                             |
| -------------- | ------------------------------ |
| APFS 已用/可用 | 约 57 GB / 188 GB              |
| 系统 footprint | 5.4–5.6 GiB                    |
| CPU 空闲       | ~99%                           |
| swap           | 0                              |
| 小组件分组内存 | ~20 MiB（进阶停用后）          |
| Siri 分组内存  | ~150 MiB（偏好已关，进程驻留） |

读数口径：`top` PhysMem、`vm_stat` anonymous/reusable、进程 MEM 与
footprint 相互重叠，取其一即可；APFS 用量与 `du` 因克隆/共享空间而不同。
判断负担看 CPU、内存压力、压缩与换页。
