# 采集、任务与恢复

## 状态与历史

节点连接、采集器新鲜度、历史保存分别判断。采集器停止后保留最后读数，并标记过期；不会用轮询时间把旧值写成新样本。系统、macmon、风扇的有效期为 10 秒，热状态为 30 秒，主机静态信息为 180 秒。集群汇总排除过期系统指标。明确为空的 macmon 路径表示禁用。

SQLite 在独立 Worker 中执行，保留 WAL 和 `synchronous=FULL`。正常每 5 秒合并一批写入；正常退出排空在途轮询和已接受的数据库请求。突然断电或强制终止可能损失尚未提交的最多约 5 秒采样，不影响已经提交的事务。操作任务的持久化回执不使用这个采样缓冲。

数据库工作队列上限为 256 个请求；采样重试缓冲上限为 3,600 条。持续无法写入时保留较新的样本，累计显示丢弃数量，同时继续实时监测。恢复后重试保留的数据。启动去重使用原始采集时间水位，独立于图表的时间分桶。

新增历史聚合保存样本数，跨层均值按样本数加权。旧版已经压缩的数据无法恢复原始样本数，迁移时每个旧桶计为一个观测；旧桶之间仍是近似权重。旧版已生成的历史记录保留，不追溯改写。新增时间索引可能让首次启动的数据库初始化稍慢，但不会阻塞主线程。

## 目录扫描

使用 macOS 自带 `du --libxo json` 的结构化路径，支持真实文件名中的换行和制表符。stdout 上限 16 MiB，stderr 上限 1 MiB，最多解析 100,000 条目录记录。超限任务失败并保留旧结果，可降低预取深度或按需扫描子目录。

扫描、取消、完成保存使用独立控制锁；序列化及磁盘同步在后台执行，不占用主监测状态锁。保存失败不丢弃上次成功结果，取消信号仍会送达子进程。新浅层结果保留深层缓存时，也保留其时间戳并向上汇总不可读状态。只有相应子树重新成功扫描后，才清除其权限缺口。

Agent 的目录修订号由本次启动身份与最近成功扫描组成。普通 `/snapshot` 仍返回完整树；带相同 `disk_revision` 的请求省略未变目录。Console 按已知修订恢复旧树，WebSocket 每次新连接发送完整基线，随后省略未变目录。任务进度始终发送；重连或 Agent 重启重新建立完整基线。

## Runner 本地操作

启停、互斥和中断始终由节点本地执行。请求包含 `request_id`，Agent 先同步保存任务，再返回接受回执。相同 ID 与相同命令返回同一任务；ID 被不同命令复用时拒绝。节点最近保留 32 条操作记录，存放于 `~/.local/state/mini-archipel/ci/runner-operations.json`。

任务区分排队、运行、完成、失败、结果不确定与重启中断。提交成功只表示已接受，页面继续显示任务状态；超时和结果无法保存不会冒充明确失败。重启后的未完成操作标记为中断，不自动重复执行，应核对 Listener、Worker 或互斥状态再决定下一步。

进程状态每秒发布，工作区大小独立低频计算，避免大工作区阻塞接单状态。不同插件的操作独立执行；插件切换只等待自己的在途操作，取消请求不受其他插件长操作阻塞。

中断前重新核验仓库、路径、UID、PID 和进程启动身份，先冻结可归属的进程树，再终止后代与 Worker，保留 Listener。隔离测试覆盖持续 fork 和独立 session 的后代。**发起中断前已脱离祖先关系、成为孤儿的进程无法仅凭普通进程表安全归属**，不会通过模糊进程名或全用户范围杀进程来猜测。中断失败时恢复仍可核验的暂停进程，并返回不确定结果。

## 升级与签名恢复

`agent/build.sh` 构建后使用现有持续身份签名。安装器在停止旧服务前校验严格签名、固定标识和已安装程序的 designated requirement；不接受 ad hoc 或意外变化的身份。Agent 和 Console 的 LaunchAgent 固定 `Umask=63`（077），私有状态与日志目录为 0700。升级和回滚均等待实际 PID 退出，不能只凭 launchd label 消失判断结束。

Console 发布必须同时包含 `server.cjs`、`store-worker.cjs` 和整个 `web/`。配置、扫描结果和 SQLite 不在发布目录中。安装器保留上一版程序和 plist，失败时按替换阶段回滚；旧 PID 未退出时保留备份并拒绝重叠启动。

签名恢复材料通过 `provisioning/scripts/backup-signing.py` 直接流式加密，包含 signing 目录及专用 keychain；不生成明文归档。运维日备份同时包含该密文和 Runner 操作记录。签名私钥、恢复私钥与令牌不得加入 Git。恢复演练应解密到私有临时目录，从证书与私钥重建专用 keychain，签署测试副本并核对原 designated requirement；仅能还原已签程序不能证明私钥可恢复。
