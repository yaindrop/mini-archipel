两台实体机解析后的完整策略及传感器列表相同，原文件注释不强行统一。基础档归还 Apple 自动温控，所以实际空闲转速可不同；这不是策略漂移。没有运行真实全核校准或中断任何 CI 作业。

生产 Console 的全部 60 个文件与本地通过验证的构建摘要一致。真实浏览器核对全局风扇页面、节点风扇页面和实际曲线，无页面异常。四节点在线，四仓库共 16 个 Runner 均在线。历史节点键 mini-1、mini-2 保留，展示名仍为 yd-mini、yd-mini-2。

安装迭代发现并修复两项问题：launchd 的 umask 077 导致 IPC 父目录不可遍历；bootout 异步退出期间重新 bootstrap 失败。现已显式设置目录权限，检查所有者，等待旧作业及 PID 消失，启动有界重试，健康检查以普通 Agent 账户执行。两台失败安装均回退了旧服务，最终安装和普通账户读写验证通过。
