# 后台运维验收 · 2026-10-18

## 已部署的行为

- 目录扫描由本地异步子进程执行，状态及最近完整结果以权限 600 原子持久化。
  请求幂等，任务 ID 稳定；扫描、失败、取消和重启期间保留旧结果，全部根目录完成且
  保存成功后才发布新结果。取消终止并回收子进程；正常退出也回收扫描进程。
- 刷新页面从节点恢复扫描状态及取消按钮；暂停资源读数仍更新连接状态、扫描任务和插件操作。
- Runner 插件支持本地中断：复核仓库、安装目录、预期 Worker PID、用户及进程身份，
  终止该 Worker 与已识别的同用户子进程。保留 Listener，不调用 GitHub 取消接口。
- 顶栏删除右上角 M，右侧保留语言、主题、退出三个图标；状态、时间及暂停键在中间。

## 检查范围

- Agent：fmt、Clippy、8 项 Rust 测试、release 构建；两个真实 HTTP 集成测试。
  单 Tokio 工作线程验证扫描不堵塞服务，涵盖幂等、过期任务取消拒绝、取消、重启恢复。
- 中断集成使用隔离的真实进程树，验证错误 PID 和忙碌启停被拒绝，Worker 及子进程退出，
  Listener 和无关进程存活。没有为了测试而中断实际 CI 作业。
- Console：中英文同步及无遗漏、类型、lint、Biome、格式、未使用代码、覆盖率和生产构建。
  82 项单元测试通过，包含暂停一分钟后操作状态仍有效、资源读数保持冻结的专项测试。
- 浏览器：12 项扫描、刷新、取消、中断、顶栏及双语检查，6 项无障碍和视觉检查，
  3 项最终暂停回归，覆盖 Chromium、WebKit、移动视口。

## 完整新扫描的待办

长扫描当前受 macOS 隐私授权阻挡。系统日志明确出现 Agent 的 Photos 授权请求；两台
虚拟机另有旧 Full Disk Access 代码要求与当前二进制不匹配的记录。默认 I/O 策略及
Interactive 的对照没有解决，所有实验进程及设置已清理或恢复。

需要用户在四台节点「系统设置 → 隐私与安全性 → 完全磁盘访问权限」中移除旧 Agent
条目并重新添加 `~/.local/libexec/mini-archipel-agent`。该操作不能由普通命令行授予。
目前已取消等待授权的扫描，旧数据仍可查看；授权后需要重新扫描并补记完整新结果。
此项未完成，不能将旧缓存结果或可取消性测试记作新扫描已成功。

本轮没有更换 `du` 为其他枚举引擎，也没有添加 SSH 扫描或绕过隐私控制；选型依据见
[扫描设计记录](../../docs/design.md#后台目录扫描2026-10-18)。
