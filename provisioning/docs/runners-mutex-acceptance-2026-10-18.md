# 节点 Runner 接单互斥验收 · 2026-10-18

## 交付行为

Runners 插件 2.1.0 在全局 Runners 页和节点详情提供同一个节点级开关，默认关闭。
开启后，共用开始钩子在进入工作流步骤前暂停其他空闲 Runner 的本地 Listener，
完成钩子在作业与维护结束后恢复。同步到达的作业等待节点租约，保留接收取消的能力。
仅恢复本策略暂停的进程，手动停止的 Runner 保持停止。

设置与恢复记录原子保存，Agent 重启保留；Worker 异常退出或本地中断时由 Agent
恢复检查收尾。服务手动启停也进入同一文件锁，避免绕过正在生效的互斥策略。
详细语义、原有节点租约与故障恢复见 [Runner 运维说明](08-github-runner.md#节点接单互斥)。
